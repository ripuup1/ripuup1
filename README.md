### What I build

**Production client sites** — Next.js App Router builds for nonprofits, real estate, hospitality, and trades. Headless CMS integration, internationalization, structured data and technical SEO, and component systems built to be handed off and maintained by someone else.

**Booking and payments** — a shared Supabase backend behind several luxury-rental property sites: availability calendars, reservation flow, Stripe deposits, iCal sync with external channels, and an owner-facing admin dashboard.

**Content platforms** — a custom MDX publishing pipeline with generated RSS and sitemaps, and a CMS migration covering 650+ posts with multi-language routing.

**Internal tooling** — retrieval pipelines on the Claude API, scheduled automation agents, and the dashboards that run the agency day to day.
